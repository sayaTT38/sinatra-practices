# メモアプリ

## 動作環境
 * Ruby 4.0.2

## セットアップ
以下のコマンドを実行してリポジトリを取得します。
```bash
git clone https://github.com/sayaTT38/sinatra-practices.git
```

取得したリポジトリへ移動し、必要なGemをインストールした後、アプリケーションを起動します。
```bash
cd sinatra-practices
bundle install
bundle exec ruby lib/memo_app.rb
```

起動後、ブラウザで以下へアクセスしてください。

http://localhost:4567

## 使用技術
 * Ruby
 * Sinatra
 * JSON
